# Haven demo plan

## User and problem
Adults who struggle with binge eating or purging may want a gentle space to talk after a difficult meal. User research and clinical validation are not established by this repository review.

## One journey
Saved companion → voice conversation → preference memory → new chat recalls the preference.

## Stack
Next.js/React/TypeScript; Supabase Auth/PostgreSQL; Claude; Cartesia; Mem0 OSS; local MiniLM embeddings; Qdrant; SQLite memory history. Local faster-whisper or optional Cartesia realtime STT.

## Honesty
Use fictional demonstration data. Verify live providers before recording. Scripted demo mode is not live AI. Memory extraction is asynchronous. No medical treatment or clinical-validation claim. Current external service availability was not tested during pitch preparation.

## Pitch
Format: two-minute recorded demo. One-liner: Haven is an AI companion for adults who struggle with binge eating or purging.
Roles: solo presenter assumed; name not supplied. Presenter narrates and drives. Detailed script, 30-second version, Q&A, and rehearsal checklist: PITCH.md.
