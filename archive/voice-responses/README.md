# Retired prerecorded call responses

The original 100 English entries and generated static reply audio have been archived here at the user's request. Live calls always use contextual Claude generation and Cartesia speech. The runtime quick-response flag is hard-disabled; legacy playback-state and history handling remain for existing records. Welcome-home audio is separate and remains active in `.voice-cache`.

`library.ts` is retained for reference and historical unit tests. `audio/` is ignored and must not be deployed as an active library. No personal user audio or transcripts are archived here.
