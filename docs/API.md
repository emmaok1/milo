# API contract

Base: `/api`. JSON bodies and responses unless noted. All non-GET requests require an exact matching `Origin` configured through APP_ORIGIN. Sensitive values never belong in URLs. All private endpoints verify a Supabase session or an explicitly enabled, isolated fictional demo session. Client-supplied owners, permissions, or model-generated routes are never authoritative.

Common errors: 400 validation; 401 sign-in required; 403 origin/permission/account rejection; 404 nonexistent or unowned resource; 409 stale version/duplicate submission; 413 input too large; 429 bounded per-account chat rate; 503 unconfigured or unavailable service. A storage/model failure never substitutes demo behavior in live mode. Responses have no-store headers. Secrets and private message text are not logged.

## Streaming

`POST /api/chat` returns newline-delimited JSON. `meta` contains conversationId (null in temporary mode) and demo boolean. `delta` contains text only. `error` contains an actionable message without raw provider details. `done` contains completed/stopped/failed. It never includes arbitrary model-provided routes, executable code, or activation commands. Stop aborts the stream; the server records partial output state where its runtime remains connected. A hard process crash can leave `generating` state for operator review.

A request UUID may be retried only after inspecting restored history; a persisted duplicate gets 409. No navigation is triggered by keywords or quoted/negative plan requests. The Make Plan button is an explicit user action and passes only the authorized conversation UUID; private text does not appear in its URL.
